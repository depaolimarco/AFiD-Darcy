The input files contained in this folder are relative to the simulations presented in [1].
To run the code:
- copy the executable and the desidered input file in the same folder;
- rename the input file as "bou_newStyle.in";
- run the code e.g. with: mpirun -n 8 afid;
- check the output as described in example_postprocessing;

References
[1] Marco De Paoli, Guru Sreevanshu Yerragolam, Detlef Lohse, Roberto Verzicco, "AFiD-Darcy: A finite difference solver for numerical simulations of convective
porous media flows"
